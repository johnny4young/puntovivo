# Puntovivo v1.19.1 — The Linux build and automatic updates for v1.19.0

## Why this release matters

v1.19.0 was published without its Linux build, and installed desktop apps were
not offered it as an update. The check that opens the packaged app before
publishing looked for the user menu by its Spanish name from before the switch
to **usted**, so the Linux build stopped and the update feed was never
published.

v1.19.1 fixes that check and publishes every platform again. For people using
Puntovivo it carries exactly what v1.19.0 brought: the new selling screen, the
command bar, one-touch keys shared by the site, the manager's day on Hoy and
packaging barcodes.

## What changed

- The packaged app check and the end-to-end tests find the user menu by its
  current Spanish name.
- There is a Linux x64 build again, next to the macOS, Windows and web ones.
- Installed desktop apps receive this version as an automatic update.
- Release notes are now written in Spanish first, with the English version
  further down.

## Before you use it

- Coming from v1.18.1 or earlier, read the
  [v1.19.0 notes](https://github.com/johnny4young/puntovivo/releases/tag/v1.19.0):
  they cover the changes cashiers will notice and the two database migrations,
  which run on their own at startup.
- This release adds no migration and no configuration change over v1.19.0.
- Windows builds are not code-signed yet, so a downloaded update waits for
  **Restart to install update** in the tray menu instead of installing on quit.
- Production sale is still gated by fiscal certification and physical-hardware
  validation, as the
  [project status](https://github.com/johnny4young/puntovivo/blob/main/docs/PROJECT-STATUS.md)
  describes.

## Downloads

[Open the v1.19.1 GitHub release](https://github.com/johnny4young/puntovivo/releases/tag/v1.19.1)
and choose the macOS Apple Silicon archive, the Windows x64 installer, the Linux
x64 AppImage or the web bundle. The .blockmap, .yml and update-policy files
support the desktop updater and are not installers.

For engineers and auditors, the
[v1.19.0...v1.19.1 comparison](https://github.com/johnny4young/puntovivo/compare/v1.19.0...v1.19.1)
shows every change behind these notes.
