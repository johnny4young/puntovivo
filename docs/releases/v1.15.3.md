# Puntovivo v1.15.3 — Readable kitchen and cash-close screens

**Language:** English · [Español](../es/releases/v1.15.3.md)

## Why this release matters

Kitchen staff and cashiers need screens they can read in the theme selected for
this computer. This maintenance release makes the kitchen display follow the
active theme and improves the legibility of cash-close panels in dark mode.

## What changed

- The kitchen display follows the active light or dark theme instead of
  inverting it.
- Cash-close panels remain legible in dark mode.

These are the changes recorded for v1.15.3 in the
[technical changelog](../../CHANGELOG.md#1153-2026-10-19). The two kitchen-display
commits describe the same operator outcome; they are not separate features.

## Before you use it

This is a retrospective note for the existing v1.15.3 tag, not a new release or a
claim that its binaries were rebuilt or requalified. The changelog labels the
release 2026-10-19; GitHub records publication on 2026-10-21. Adding this file does
not rewrite the tag or the published GitHub release body.

The [project status](../PROJECT-STATUS.md) remains the source for limitations.
Physical-printer qualification and fiscal certification are still separate
requirements. This note does not claim that later catalog or dependency repairs
