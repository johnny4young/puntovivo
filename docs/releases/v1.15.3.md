# Puntovivo v1.15.3 — Readable kitchen and cash-close screens

## Why this release matters

v1.15.3 is a small maintenance release for two screens that staff read all
shift long. The kitchen display inverted the active theme, so a register in
light mode showed a dark kitchen screen and the other way round. The cash-close
panels also had low-contrast text in dark mode.

## What changed

- The kitchen display follows the active light or dark theme instead of
  inverting it.
- The cash-close panels are legible in dark mode.

## Before you use it

- This release has no database migration and no configuration change.
- Production sale is still gated by fiscal certification and physical-hardware
  validation, as the
  [project status](https://github.com/johnny4young/puntovivo/blob/main/docs/PROJECT-STATUS.md)
  describes.

## Downloads

[Open the v1.15.3 GitHub release](https://github.com/johnny4young/puntovivo/releases/tag/v1.15.3)
and choose the macOS Apple Silicon archive, the Windows x64 installer, the Linux
x64 AppImage or the web bundle. The .blockmap, .yml and update-policy files
support the desktop updater and are not installers.
