# Puntovivo v1.15.6 — Search that reaches the whole catalog

## Why this release matters

v1.15.6 fixes three places where a screen only looked at the first page of the
catalog. On a store with a large catalog, the inventory search filtered only
the rows already loaded while the totals above it counted everything. A saved
sales favorite disappeared when its product fell outside the first 80 results.
The quotation editor could not select a product beyond the first 200 rows.

All three screens now ask the server for the products that match, so what you
search for is what you get, however large the catalog is.

## What changed

- Inventory stock search sends the name or SKU to the server. The table, the
  export and the stock totals now describe the same filtered set, and the note
  under the totals says they cover every matching product across all pages.
- Sales quick access loads each saved favorite directly, so a favorite stays on
  screen wherever it sits in the catalog. Tapping it reads the current product
  before adding it to the cart. A favorite whose product was removed drops out
  quietly instead of showing an error.
- The quotation editor has a catalog search by name or SKU. Lines you already
  added keep their product and the price you chose while you search for the
  next one, and only active products are offered.

## Before you use it

- This release has no database migration and no configuration change.
- The inventory stock table still shows up to 100 matching products at a time.
  The totals cover every match, so narrow the search to see a specific product.
- Production sale is still gated by fiscal certification and physical-hardware
  validation, as the
  [project status](https://github.com/johnny4young/puntovivo/blob/main/docs/PROJECT-STATUS.md)
  describes.
