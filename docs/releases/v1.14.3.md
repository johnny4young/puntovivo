# Puntovivo v1.14.3 — the desktop spellchecker is off

## Why this release matters

v1.14.3 is a small desktop release. The desktop app no longer uses Electron's
built-in spellchecker, which Puntovivo had never configured. On Windows and
Linux that spellchecker downloads its dictionaries from the Chromium CDN by
default, a network dependency an offline-first register should not have. It
also could not tell which language was being typed and offered no suggestions,
so its only visible effect was red underlines under correct codes, names and
Spanish text.

The release checks behind the desktop builds were also tightened, so a real
problem is less likely to pass as harmless noise.

## What changed

### Desktop text fields

- The built-in spellchecker is off for every desktop window, including the
  Customer Display, and for the desktop session as a whole.
- Typing in desktop text fields no longer shows spelling underlines.
- On macOS, typed text is no longer sent to the system spell server for
  checking.
- The web app in a browser is unchanged and keeps each browser's own spellcheck
  behavior.

### Release checks

- The packaged app check that every release runs now fails when a harmless
  macOS message repeats more often than a healthy run produces, so a persistent
  failure cannot hide behind it.
- Continuous integration now runs each script test whenever that script, or a
  file it reads, changes. That includes the checks for curated release notes
  and for the release workflow itself.

## Before you use it

- There are no database migrations and no changes to screens, data or
  permissions. The only visible difference is that spelling mistakes in desktop
  free-text fields, such as product names or notes, are no longer underlined.
- Every desktop build of this release published, and the update feed offers
  v1.14.3 to installed registers starting with a 10% staged rollout.
- macOS verifies an update's code signature and can install it on quit. Windows
  and Linux download the update but install it only when someone restarts into
  it from the app. The Windows installer is not code-signed, and Windows may
  warn before running it.
- Production sale is still gated by fiscal certification and physical-hardware
  validation, as the
  [project status](https://github.com/johnny4young/puntovivo/blob/main/docs/PROJECT-STATUS.md)
  describes.
