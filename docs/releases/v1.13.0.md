# Puntovivo v1.13.0 — the v1.11.1 application under a new version number

## Why this release matters

v1.13.0 contains exactly the same application as v1.11.1. Between the two
tags, only version numbers, the release manifest and the generated changelog
changed. A 1.12.0 version was prepared in between but never published as a
release, which is why there is no v1.12.0.

The changelog generated for v1.13.0 lists a long series of features and fixes.
Every one of those entries describes earlier work that already shipped in
v1.11.1 or before; none of it is new in v1.13.0. These curated notes exist so
nobody reads that list as a description of this release, and so anyone who
installed v1.13.0 knows what they are actually running.

## What changed

- The version moved from 1.11.1 to 1.13.0 in the application manifests and the
  release manifest.
- The changelog gained generated 1.12.0 and 1.13.0 sections.
- No application, database, desktop or web code changed. An installation that
  moves from v1.11.1 to v1.13.0 behaves exactly the same, with no new database
  migrations.

For what the software does at this version, read the
[v1.11.1 notes](https://github.com/johnny4young/puntovivo/releases/tag/v1.11.1)
and the
[v1.11.0 notes](https://github.com/johnny4young/puntovivo/releases/tag/v1.11.0).

## Before you use it

- These notes were written on 2026-09-13, after v1.14.2, to replace the
  generated notes this release was published with. For a desktop installation,
  use v1.14.2 or later.
- Only the Linux AppImage and the web bundle were published. The macOS build was
  signed and notarized but failed its packaged-app check on two harmless macOS
  messages, which v1.14.2 classified. The Windows build failed the same check on
  a Windows file-sync error in the updater, which v1.14.1 fixed.
- Installed desktop registers were not offered this release automatically,
  because the update feed is published only when every desktop build succeeds.
- Everything said about v1.11.1 applies here too, including the requirement for
  a standalone server to provide its database encryption key.
- Production sale is still gated by fiscal certification and physical-hardware
  validation, as the
  [project status](https://github.com/johnny4young/puntovivo/blob/main/docs/PROJECT-STATUS.md)
  describes.
