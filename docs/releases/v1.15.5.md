# Puntovivo v1.15.5 — A setup check you can believe

## Why this release matters

v1.15.5 is a maintenance release for people who build Puntovivo from source.
The setup check reported a fresh checkout as broken: it marked the desktop
runtime that is installed on first launch, and dev servers that had not been
started yet, as failures. It also reported success when a check had really
failed, so a broken database driver could pass unnoticed. The setup guides
named a looser pnpm version than the one the repository pins.

The running app is unchanged. This release only touches the setup check and
the guides that explain how to install from source.

## What changed

- The setup check shows a fresh checkout as ready, with a note and the command
  to run for anything that is only prepared on first launch.
- A desktop runtime left half-installed by an interrupted download is now
  reported as broken, with the repair command, instead of as installed.
- The setup check exits with an error whenever a check fails, so scripts that
  run it can trust the result.
- The English and Spanish setup guides start from a fresh clone, name pnpm
  11.7.0, install with the locked dependency versions and explain how to get
  Corepack on Node.js 25 and later.

## Before you use it

- This release has no database migration, no configuration change and no
  change to the installed app.
- Production sale is still gated by fiscal certification and physical-hardware
  validation, as the
  [project status](https://github.com/johnny4young/puntovivo/blob/main/docs/PROJECT-STATUS.md)
  describes.
