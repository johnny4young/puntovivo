# Puntovivo v1.19.2 — Migrate your catalog with all three prices

## Why this release matters

People who move to Puntovivo from another point of sale usually bring their
catalog in one file with three price levels. Until now the import kept only the
first one, left price 2 and price 3 at zero, accepted up to 500 products per
file and garbled the accents and ñ of CSV files created on Windows. The import
option was also hidden inside **Manage business**.

v1.19.2 brings a catalog of hundreds of products in a single file, with its
three prices, exactly as it comes out of the previous system.

## What changed

- The product import saves **Price 2** and **Price 3**, along with the sale
  price and the cost. At the register, price lists P2 and P3 use those values
  from the first sale.
- The columns **Código**, **Nombre del producto**, **Costo**, **Precio 1**,
  **Precio 2** and **Precio 3** map on their own, and so do **P1**, **P2** and
  **P3**.
- CSV files saved on Windows keep their accents and ñ. They no longer need to
  be converted to UTF-8 before upload.
- A product file accepts up to **2,000 rows**. The other imports (customers,
  providers, balances, opening cash and fiscal profiles) stay at 500.
- Administrators see an **Import products** button on the Products page, next
  to **Add Product**.
- When the file carries no stock column, products start with zero stock.

## Before you use it

- Only an **administrator** can import.
- Create an encrypted backup before importing real data. An import has no
  one-click undo; products repeated by code or barcode are skipped, not updated.
- This release adds no database migration and no configuration change over
  v1.19.1.
- Windows builds are not code-signed yet, so a downloaded update waits for
  **Restart to install update** in the tray menu instead of installing on quit.
- Production sale is still gated by fiscal certification and physical-hardware
  validation, as the
  [project status](https://github.com/johnny4young/puntovivo/blob/main/docs/PROJECT-STATUS.md)
  describes.
