# Puntovivo v1.19.1 — La versión para Linux y las actualizaciones automáticas de v1.19.0

## Por qué importa este release

v1.19.0 se publicó sin la versión para Linux, y las aplicaciones de escritorio
ya instaladas no la recibieron como actualización. La prueba que abre la
aplicación empaquetada antes de publicarla buscaba el menú de usuario con el
texto en español anterior al cambio a **usted**, así que la versión para Linux
se detuvo y la publicación de actualizaciones no se ejecutó.

v1.19.1 corrige esa prueba y vuelve a publicar todas las plataformas. Trae
exactamente lo mismo que v1.19.0 para quien usa Puntovivo: la nueva pantalla de
venta, la barra de comandos, las teclas de un toque compartidas por la sede, el
día del gerente en Hoy y los códigos de barras por empaque.

## Qué cambió

- La prueba de la aplicación empaquetada y las pruebas de extremo a extremo
  reconocen el menú de usuario con su nombre actual en español.
- Hay versión para Linux x64 otra vez, junto a las de macOS, Windows y web.
- Las aplicaciones de escritorio instaladas reciben esta versión como
  actualización automática.
- Las notas de release ahora se escriben primero en español, con su versión en
  inglés más abajo.

## Antes de usarlo

- Si viene de v1.18.1 o anterior, lea las
  [notas de v1.19.0](https://github.com/johnny4young/puntovivo/releases/tag/v1.19.0):
  ahí están los cambios que verán los cajeros y las dos migraciones de base de
  datos, que se ejecutan solas al iniciar.
- Este release no agrega migraciones ni cambios de configuración frente a
  v1.19.0.
- Las versiones para Windows todavía no están firmadas, así que una
  actualización descargada espera a **Reiniciar para instalar la actualización**
  en el menú de la bandeja en lugar de instalarse al salir.
- La venta en producción sigue condicionada a la certificación fiscal y a la
  validación en hardware físico, como describe el
  [estado del proyecto](https://github.com/johnny4young/puntovivo/blob/main/docs/es/PROJECT-STATUS.md).

## Descargas

[Abra el release v1.19.1 en GitHub](https://github.com/johnny4young/puntovivo/releases/tag/v1.19.1)
y elija el archivo para macOS Apple Silicon, el instalador para Windows x64, el
AppImage para Linux x64 o el paquete web. Los archivos .blockmap, .yml y de
política de actualización sirven al actualizador de escritorio y no son
instaladores.

Para ingeniería y auditoría, la
[comparación v1.19.0...v1.19.1](https://github.com/johnny4young/puntovivo/compare/v1.19.0...v1.19.1)
muestra cada cambio detrás de estas notas.
